# 어느 출구로 나오나

인천공항 도착편의 **입국장 출구**를 편명으로 바로 확인하는 도구.
수하물 벨트 번호로 출구를 추측하지 않고, 공항이 배정한 값을 그대로 보여줍니다.

## 1. 서비스키 발급

공공데이터포털에서 신청합니다. 승인은 보통 즉시 또는 1시간 이내.

- 인천국제공항공사_여객기 운항 현황 상세 조회
  https://www.data.go.kr/data/15112968/openapi.do

마이페이지 → 오픈API → 인증키에서 **일반 인증키(Decoding)** 값을 복사합니다.
개발계정은 하루 500건, 운영계정 신청 시 늘어납니다.

## 2. 먼저 CLI 로 확인

```bash
export ODP_SERVICE_KEY="발급받은_Decoding_키"
python check_flight.py VN414

# 응답 필드명을 눈으로 확인하고 싶을 때
python check_flight.py VN414 --raw
```

`--raw` 를 꼭 한 번 돌려보세요. 공공데이터 API 는 문서와 실제 필드명이
다른 경우가 있어서, 두 코드 모두 후보 키를 여러 개 두고 찾는 방식으로
짰습니다. 원본을 보고 안 잡히는 필드가 있으면 `FIELDS` 사전에
실제 키 이름을 추가하면 됩니다.

## 3. Vercel 배포

```bash
npx vercel
```

배포 후 프로젝트 설정 → Environment Variables 에서:

| 이름 | 값 |
|---|---|
| `ODP_SERVICE_KEY` | 일반 인증키 Decoding 값 |

키는 서버리스 함수 안에서만 쓰이고 브라우저로 나가지 않습니다.

## 구조

```
api/arrival.js      공공데이터포털 호출 프록시 (CORS·키 은닉)
public/index.html   조회 화면
check_flight.py     터미널용 CLI
```

브라우저에서 `apis.data.go.kr` 을 직접 부르면 CORS 로 막히기 때문에
프록시가 반드시 필요합니다.

## 알아둘 점

- 이 API 는 **조회 시점 기준 앞뒤 약 2시간** 도착편만 반환합니다.
  내일 도착하는 편은 안 나옵니다.
- 입국장 출구는 당일 배정값이라 도착 직전에 바뀔 수 있습니다.
  실제로 `D → C` 처럼 변경되는 경우가 흔합니다.
- 코드셰어 편명(예: KE5690)으로도 검색되도록 마스터 편명까지 비교합니다.
- 편명은 `VN414`, `VN 414`, `vn0414` 모두 같은 편으로 인식합니다.

## 검증 안 된 부분

서비스키가 없어 실제 응답으로 테스트하지 못했습니다. 아래 두 가지는
`--raw` 출력으로 확인한 뒤 필요하면 고칠야 합니다.

1. 요청 파라미터 이름 (`from_time`, `to_time`, `terminal_id`)
   — 현재는 없어도 동작하도록 선택 항목으로만 붙여뒀습니다.
2. 응답 필드 이름 — `FIELDS` 사전의 후보 목록으로 대응 중입니다.
